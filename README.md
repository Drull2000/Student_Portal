# Компьютерная Инженерия

Простой статический портал группы с расписанием, онлайн-занятиями и важными ссылками.

## Как открыть сайт

Откройте `index.html` в браузере. Для стабильной работы PDF и iframe лучше использовать небольшой локальный сервер, например Live Server в VS Code, или разместить сайт на любом статическом хостинге.

## Как добавить расписание PDF

1. Положите текущий PDF в папку `assets/`.
2. Назовите файл `schedule.pdf`.
3. Главная страница автоматически покажет этот файл.
4. При изменении расписания просто замените PDF новым файлом с тем же именем.

PDF доступен только для просмотра. На главной странице есть кнопки для открытия в новой вкладке и скачивания.

## Как заменить значок на фотографию

Положите свою фотографию в папку `assets/` и назовите её `logo.jpg`. Она автоматически появится слева от названия сайта на всех страницах.

Если используется другой формат, например PNG, замените `logo.jpg` на `logo.png` в тегах `img` в HTML-файлах.

## Как изменить настройки сайта

Откройте `js/main.js` и измените объект `PORTAL_CONFIG`:

```js
const PORTAL_CONFIG = {
    portalName: 'Компьютерная Инженерия',
    specialty: 'Компьютерная Инженерия',
    group: 'КИ-21',
    googleDocsUrl: 'https://docs.google.com/document/d/ВАШ_ID/edit?usp=sharing'
};
```

Меняйте название специальности, группы и ссылку Google Docs только в этом объекте. Значения используются на всех страницах. После добавления ссылки таблица будет загружаться автоматически при открытии `schedule.html`.

Для Google Docs установите доступ **Все, у кого есть ссылка — читатель**. На странице расписания есть отдельная кнопка на случай, если просмотр внутри сайта недоступен.

## Как добавить занятия Zoom

Откройте `js/zoom.js` и добавьте объекты в массив `zoomLessons`:

```js
{
    name: 'Mathematics',
    teacher: 'Имя преподавателя',
    description: 'Weekly online lesson.',
    url: 'https://zoom.us/...'
}
```

Для новых занятий используйте такую же структуру. Если ссылки пока нет, оставьте `url` пустым: вместо неработающей кнопки появится сообщение `Ссылка пока не добавлена.`

## Как добавить классы Google Classroom

Откройте `js/classroom.js` и добавьте объекты в `classroomLessons` с полями `name`, `teacher`, `description` и `url`.

## Как добавить группы Телеграмм

Откройте `js/telegram.js` и добавьте объекты в `telegramGroups` с полями `name`, `description` и `url`.

Если массив пустой, страница покажет понятное сообщение, что ссылки ещё не добавлены.

## Размещение через GitHub Pages

1. Создайте репозиторий на GitHub.
2. Загрузите в него этот проект, включая `assets/schedule.pdf`.
3. Откройте в репозитории **Settings**, затем **Pages**.
4. Выберите **Deploy from a branch**.
5. Укажите основную ветку и корневую папку.
6. Сохраните настройки и откройте созданную ссылку GitHub Pages.

В проекте нет серверной части, базы данных или сборки, поэтому его также можно разместить на Netlify, Vercel или любом другом статическом хостинге.
